# Prompt Library Mini Project

This is a small **Prompt Library** created as part of my Generative AI course. The project focuses on using prompt engineering techniques to get better and more useful responses from AI tools like ChatGPT.

## What I Created

I created **10 reusable prompts** for:

1. LinkedIn Post
2. Instagram Post
3. Blog Introduction
4. Cold Outreach Email
5. Follow-up Email
6. Product Description
7. YouTube Title & Description
8. Newsletter Section
9. Article Summarization
10. Tone Rewriter

## Techniques Used

* RTCF Framework
* Zero-Shot Prompting
* Few-Shot Prompting
* Role Prompting
* Chain-of-Thought
* Constraints & Format Control
* Iterative Refinement

## Learning

This project helped me learn that **clear instructions, context, and constraints can improve AI responses**. I also learned how to refine prompts step by step to get better results.
