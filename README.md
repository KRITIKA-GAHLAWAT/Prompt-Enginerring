Prompt Engineering & AI Story Generator

This repository contains two mini projects created as part of my Generative AI / Prompt Engineering course. The projects focus on understanding prompt engineering techniques and using the Google Gemini API to generate creative content.

Projects Included
1. Prompt Library Mini Project

The Prompt Library contains 10 reusable prompts designed for different content-generation tasks.

The prompts cover:

LinkedIn Post
Instagram Post
Blog Introduction
Cold Outreach Email
Follow-up Email
Product Description
YouTube Title & Description
Newsletter Section
Article Summarization
Tone Rewriter

The main objective of this project is to understand how clear instructions, context, roles, examples, and constraints can improve the quality of AI-generated responses.

2. AI Story Generator

The Story Generator is a Python-based mini project that uses the Google Gemini API to generate stories based on user inputs.

The user provides:

Topic – the subject or idea of the story
Genre – the type of story, such as Fantasy, Mystery, Science Fiction, etc.

The program then sends these inputs to the Gemini model and generates a creative story.
