# Prompt Engineering and AI Story Generator

This repository contains two mini projects created as part of my Generative AI and Prompt Engineering course.

The projects focus on understanding prompt engineering techniques and building a simple AI powered Story Generator using the Google Gemini API.

## Projects Included

### 1. Prompt Library Mini Project

This project contains 10 reusable prompts created for different content generation tasks.

The prompts include:

1. LinkedIn Post
2. Instagram Post
3. Blog Introduction
4. Cold Outreach Email
5. Follow-up Email
6. Product Description
7. YouTube Title and Description
8. Newsletter Section
9. Article Summarization
10. Tone Rewriter

### 2. AI Story Generator

This is a Python based mini project that uses the Google Gemini API to generate creative stories based on user inputs.

The user provides:

Topic: The subject or idea of the story

Genre: The type of story, such as Fantasy, Mystery, Science Fiction, etc.

The AI then generates a story based on the given inputs.
